# Spec — M1 "Playable night"
<!-- Spec = intent, not law. Before a big system is built, its owner turns the relevant part into docs/blueprints/<system>.md. -->

## Goal
Prove the core loop is fun in the smallest slice: one squad in the Game Place gathers wood and stone, builds walls, then survives (or doesn't) one night of one enemy type.

## In scope
- Game Place skeleton: folders, `Main`, `ClientMain`, `Remotes` (see places/Game/CONTEXT.md).
- Map blockout: ~300×300-stud scrapyard, central `BasePlot`, ~20 wood nodes (dead trees) + ~20 stone nodes (rock piles) around it.
- Run flow: `Day (short, test timing) → Dusk → Night → Dawn/Win` or `Lose` (all players down). Phase + timer replicated to clients.
- Day/night lighting tied to the phase.
- Gathering: hit a node (tool swing / interact button), node loses HP, player gains resources; nodes respawn.
- Resource inventory: wood, stone per player, server-side.
- Building: place a wall segment on a grid inside `BasePlot` for a wood/stone cost; walls have HP.
- Combat: player health; one basic melee weapon (scrap pipe) that hits enemies.
- Enemy "Howler": blind melee mutant that hunts by sound (glowing Mutant-green throat sac, shriek on lock-on). In M1 it targets the nearest player, or the wall blocking its path; from M2 it is drawn to the loudest Noise source.
- One night wave: fixed count (tune) of Howlers spawning from the map edge.
- HUD: wood/stone counts, phase + timer, health, build button + build mode, all input types.

## Out of scope (later milestones)
Noise, crafting, scrap, loot/POIs, turrets/traps, multiple nights, boss, Lobby, saves, teleport, salvage.

## Acceptance criteria
- A 1-player and a 2+-player Studio playtest (Team Test or local server) complete Day → Night → Win, and a Lose path.
- Every action works with keyboard/mouse, gamepad and touch (verify with Studio device emulation).
- No UI generated by script; all panels are authored ScreenGuis.
- `[Test]` prints show: phase changes, resource gains, wall placement, enemy spawns/deaths, win/lose. Debug flags off at landing.
